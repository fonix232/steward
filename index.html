Steward package feed

A UniFi-style network controller for OpenWrt — github.com/fonix232/steward

Install (OpenWrt 25.12 and later)

On the device that hosts the controller (usually the router):

wget -O /etc/apk/keys/steward.pem https://fonix232.github.io/steward/steward.pem
apk add -X https://fonix232.github.io/steward/apk/$(cat /etc/apk/arch)/packages.adb steward

On every other device (access points, switches), install steward-agent instead of steward. The agent adds this feed to the device, so later versions arrive with apk upgrade.
